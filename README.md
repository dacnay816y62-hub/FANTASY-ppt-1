# FANTASY PPT SKILL

一个会做概念设计的 PPT Skill。

用于室内、建筑、酒店、餐厅、零售与住宅的空间设计概念提案。采用简约的品牌排版与设计师的汇报框架。

## 本次更新

- 多图概念氛围页用逐图概念词共同表达项目方向，保留已认可的图片与可编辑文字。
- 提案以项目化的设计愿景与「谢谢 / THANK YOU」收尾，配合项目氛围底图。
- 关键词与构图按项目选择，不固定四词或同一套结尾模板。

## 使用

将本仓库下载后作为技能目录导入支持 SKILL.md 的环境。入口为 [SKILL.md](SKILL.md)，调用名称为 `ppt-image-deck`。按任务读取 references 中的指南，assets 为排版参考，scripts 提供检查辅助。

参考图仅供学习排版，不作为新项目的实景或直接交付素材。字体与图片仍遵循各自的使用许可。
