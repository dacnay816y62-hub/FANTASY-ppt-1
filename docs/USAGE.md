# 使用方法与项目输入

## 推荐任务书

```text
项目名称：
项目类型：酒店 / 民宿 / 餐饮 / 商业 / 住宅 / 其他
地点：城市、街区；准确地址如已知
面积：已知数值或模拟范围
使用人群与经营目标：
主要功能：
空间气质与材料方向：
当地文化或历史线索：
必须参考的图片：逐张说明喜欢什么
明确排除的做法：
阶段：概念研究 / 完整方案 / 既有文件优化
交付：PPTX；文字是否必须可编辑；是否需要PDF和预览
已提供资料：平面、现场照片、任务书、地图、现有PPT
```

缺失条件可先标为未知。模拟案例允许合理假设，但要注明，不能自动变成真实项目事实。

## 示例一：东方私宴会所

```text
使用 $ppt-image-deck。
项目：隐园·东方私宴会所，杭州西湖景区周边，模拟面积约850㎡。
功能：门厅、接待、公共餐区、茶室、水庭、6间私宴包厢、VIP休息。
从庭院、借景、框景、光影、游园提炼空间语言，避免传统符号堆砌。
材料：深木、粗石、浅灰泥，低饱和；强调天光、窄窗和室内外渗透。
本阶段只做概念与手法。多图概念页逐图配关键词，最后加入设计愿景和谢谢。
```

## 示例二：川西民宿

```text
使用 $ppt-image-deck，制作一份川西民宿概念方案。
附件为室内氛围参考，请先拆解材料比例、光线、家具尺度和色彩。
建筑可以模拟，概念需要新，避免民族符号直接拼贴。
历史与文化仅提取能支持后续设计的部分。
分析图使用简洁线框与色块演化，重要页使用原创主视觉。
未知地址、气候参数和结构条件标明待核实。
```

## 示例三：城市咖啡店

```text
使用 $ppt-image-deck，为北京街区咖啡店制作概念提案。
定位：日常可进入、安静但有识别度，关注独处与短暂停留。
先比较两条概念方向，再选一条完成提案。区位图必须基于真实底图。
不要固定使用四图四词和同一种左右排版，根据内容调整节奏。
```

以上是可复制的模拟任务书，不代表仓库已经包含这些项目的完整 PPT。

## 对已有页面给反馈

提供源 PPT 与截图，并尽量指出页码、保留内容、问题和目标。例如：

```text
第6页四张图全部保留。分别加入“水庭、轻隔、素器、筛光”，
组成项目概念，原来的“有边界的相聚”降为辅助句。
关键词位于对应图片下方，保持原生文本，统一基线。
```

## 精简迭代方式

先解决结构，再解决概念对应关系，最后调整字号、留白和图像裁切。已经认可的图片和页面不因换模板而重做。选择能代表本项目难点的试排页即可，不必每次固定相同页数。
