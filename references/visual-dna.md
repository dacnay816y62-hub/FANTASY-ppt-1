# 视觉系统与场景一致性

## 项目视觉方向

在 `visual-dna.txt` 简记：

```text
关键词：表达目标 / 本项目要避免的偏差。
字体：封面展示字、内页标题、判断句、正文、英文或编号的字体与 pt 值。
色彩：页面基底、主文字、辅助色、强调色。
图像：素材类型、光线与明度、裁切方式、人物策略。
版式：画幅、阅读场景、网格、边距、图文关系、留白位置、页码。
差异：本项目为什么需要这些选择。
```

空间语言只在相关任务中补充：建筑、材料、家具与环境。用项目目标确定视觉方向，不默认黑金、东方、酒店摄影或同一组诗意关键词。已有品牌系统、指定模板和连续汇报应保留必要一致性，不为区别于上个项目强行换字体和主色。

## 把参考转为可执行构图

用户提到既有参考或分析时，先查可用的原图、文件与记录；区分看过的视觉证据和仅有文字记载的判断。为代表页简记“素材角色 / 比例与裁切 / 前后层次 / 背景”，例如：园林局部为主图，器物与工艺近景为辅图，生成的体积示意解释边界关系，低对比纸纹承底。不要把参考压缩为“高级、克制、东方”等风格词。

文化、元素和概念的氛围页优先使用 [固定图文模板](culture-concept-mood-templates.md) 及其六张原图。根据模板先确定跨图标题、图内叠字或图带中轴，再挑选唯美图片。氛围素材可网上筛选或生成；不要因页面含“元素/概念”便统一改为抽象模型演示。图片已经满幅承底时，无须另加纹理；概念停顿页默认保留可辨识的氛围影像，纯黑过场只在用户明确选择时使用。

丰富度应在成品里体现为可辨识的素材类别、大小比例和层次关系；增加文字、页数或页型名称并不能替代它。按页面观点选择主图、文化或生活方式证据、细部、分析示意和底纹，组织不等大的图像、局部叠合、窄幅条带或圆形裁切，不必每页全用。克制不自动等于白底单图，背景明暗与材料感仍由本项目参考和用户要求决定。

丰富也不等于满版。为主图、说明与分析图留出各自完整的空间；不要让所有图片顶满列宽、图注挤在页脚上方。用户要求品牌提案感或反馈“太满”时，参考实际内页的标题比例、文字列宽、图幅、边距和空区，而不只参考封面。保留有意义的素材类别，同时减少重复强调层、图注底框和无功能装饰；图像面积与留白随页面任务变化，不机械统一填充率。

需要质感时，将纸、织物、石材微纹理、树影等作为独立背景素材，控制使用区域与强度；正文区应安静，底纹不能降低文字和分析线的辨识度。用户明确不要白底时，全套背景沿用这一约束，不把浅纸白当作完成；可用深灰、茶褐、灰绿等符合项目参考的材质基底，不自动套黑金。此偏好只沿用到相关项目，不覆盖未来项目的品牌要求。

元素提炼、概念转译与空间策略的演示图使用 Image Gen 独立图像，配可编辑标注；通过材质、体积、光影或形态差异说明判断，不用线条方框拼装。精确工程关系、数值与尺寸仍由可靠来源和确定性工具保证，不让图像生成替代验证。分析图与氛围图是主任务时，优先完善其内容和构图，不靠补空间效果图凑丰富度。

新提案先把这些关系放进代表页整页视觉稿，再落实为无字素材与原生排版。记录主要图像位置、大小、裁切和叠层；最终 PPT 要与视觉稿对照，确认重建后仍保有相同的主次和质感。

## 概念分析的演化表达

读取 [元素演化分析](element-evolution-analysis.md)。让观众从图中看见来源、抽取的关系和变化结果：保留同一轮廓、层次、色彩或明暗锚点，使用平面线面、材质拼贴、叠合或必要的概念剖示表达。形式简化后应更容易理解，而不是更难辨认。

孤立的形态艺术图只承担氛围或局部意向；不得连续用悬浮石块、卷曲玻璃或类似棚拍雕塑代替设计手法。无需过早画成完整房间，亦不固定为三个灰白模型。先后变化确有意义时才连成演化，关系不成立时换表达。

## 同一套页面的变化

稳定字体角色、边距、标注层级和色彩关系；改变的是信息组织。

- 封面建立主题与识别。
- 分析页把依据、动作或关系讲清楚。
- 氛围页组织光、材料、生活方式等不同层面的意向。
- 空间页展示设计结果。
- 比较页可故意保持同构，帮助判断差异。

不要把这个列表变成固定页序。按论证节奏交替密度，避免连续复制左文右图、卡片或无解释的大图。克制不等于过小字号、过淡对比或大面积无功能留白。

## 何时建立母图

只有需要生成有关联的多张空间图时，才选择已通过检查的参照图。素材优先级由本次任务决定：分析和氛围排版测试可直接从图表、真实参考图或静物素材开始，无须生成空间母图。

对同一空间，固定：

- 可确认的轮廓、开口和固定家具位置；
- 墙地顶与主要构件的材料、纹理和颜色；
- 家具、器物的身份、尺度与位置关系；
- 同一时段的光线来源和环境。

允许根据说明目的改变机位、焦段、景别和裁切。细部页可以使用近景；全景页可以使用广角。日夜对比可改变时间与照明，但要明确且保持空间结构。

对同一项目的不同空间，延续材料和设计语言即可，不应复制同一间房或完全相同的灯光。不要在没有平面依据时凭单张图推断背面布局并声称已验证空间连续性。

## 简短场景记录

```text
场景 / 固定要素 / 本图说明目的 / 可变化项 / 资料限制
```

只有会影响一致性的内容才列入。检查是为了避免穿帮，不是锁死摄影方法。

## 检查问题

1. 图片、字体和版式是否支持这个项目的判断？
2. 分析页能否讲清关系，氛围页是否图像角色互补？
3. 同场景是否出现构造、材料或家具位置矛盾？
4. 相邻页的变化是否有目的，整套识别是否连贯？
