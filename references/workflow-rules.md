# 执行与返工

## 输入判断

| 输入 | 处理 |
|---|---|
| 一句项目描述或要求测试 | 明确受众和目的后选择适度篇幅；可用标明虚构的概念样例，不默认扩成十几页 |
| PDF/PPT | 区分内容依据与指定视觉模板；模板页遵循当前 Presentations 的继承编辑要求 |
| 平面图 | 保留可验证的轮廓、尺度和结构；优化部分明确为建议 |
| 效果图、实景、AI 图 | 先辨明类型；同场景多角度才需要空间一致性记录 |
| 参考案例 | 指定其角色：资料证据、内容来源、视觉参考或构图参考 |
| 资料不足 | 列出 UNKNOWN；允许设计建议，不能伪装成已确认条件 |

## 选择代表页

围绕本次任务最需要验证的能力，选少量版式不同的页面。常用封面、核心分析、视觉页；不是固定三页清单。

- 排版测试：分析图、氛围拼贴、材料映射等能检验信息层级、图片组织和页面节奏。素材够用即可，不应先花大量时间生成空间效果图。
- 方案深化：重点空间大图、真实平面分析、材料/节点页能检验空间理解和证据清晰度。
- 两页修改：检查两页即可，不为凑三页扩大范围。

新提案先做代表页整页视觉稿，方向成立后重建为 PPT 并渲染，对照确认质感、图像比例与叠层没有丢失，再完成其他页面。小范围修改或明确模板可直接编辑 PPT。用户已授权整套制作时，内部检查后继续；只有明确约定先看试做或缺失关键用户决定时才停下。

## 篇幅与叙事

页数由受众、汇报阶段、资料量和用户要求共同决定。小型测试通常 4–8 页足以覆盖主要能力；完整方案按有效内容扩展，不以模板目录补齐页数。

完整方案仍须覆盖 [文化依据、区位与对应平面](culture-site-plan.md)，效果图章节前先说明平面。压缩篇幅时可合并相关信息，不能因此跳过这些依据；用户只看局部或概念试页时，不擅自扩成完整报告。

优先保留“问题/机会 → 核心判断 → 空间动作 → 视觉或图纸证据 → 决策/下一步”。这是推导关系，不是每套固定五章。材料页说明材料在空间中的作用；文化页说明提取了什么方法、在哪里发生变化。删去不改变方案判断的泛城市介绍和情绪套词。

## 素材与排版

按代表页需要安排素材生成顺序。只有任务包含多张有关联的空间图时，才需要重点空间母图；分析或氛围任务可直接使用证据图、静物或拼贴。

- 整页视觉稿可用短标题检验构图；最终素材按区域的长宽比、裁切和文字区准备，不带入预览文字，关键文字改用 PPT 原生文本。
- 真实图纸与准确数值不交给图像模型编造。资料不足时可做不按比例的功能关系示意，明确标注。
- 相邻页按论证需要改变图文结构；比较页保留相同网格可能更利于判断，不为变化而变化。
- 连续高信息密度之后安排大图或低密度页；避免所有内容都放进卡片。
- 标题先写自然、具体的判断句，再选择字号和行数。短标题保持一行；必要的双行标题手动设计，不容忍意外换行。
- 封面与章节展示字单独设计，内页按项目文字角色稳定字号与锚点；不因某页文字较长就临时缩字，也不为统一内页而缩小已确认的封面。
- 摄影/渲染图通常用高质量 JPEG；透明素材用 PNG。图片分辨率按显示尺寸和交付需求决定。

## 返工顺序

| 问题 | 优先处理 |
|---|---|
| 方案靠漂亮词串联 | 回到条件、使用问题、设计动作，补能说明该动作的证据 |
| 未知条件被写成事实 | 删除伪精确表述或改为清楚标注的建议 |
| 多图不属于同一项目 | 检查材料、构造、家具和空间关系；不统一所有机位 |
| 文字太满/断行难看 | 删减或换版式、重写断句，再调整文本框；不靠持续缩小字号 |
| 页面像通用办公模板 | 建立主次、减少重复容器、让图片与论证发生关系 |
| 丰富度不足 | 对照参考补互补的素材角色、主辅比例和叠层；不只换底色、加文字或加空间效果图 |
| 视觉稿好看，PPT 重建变平 | 对照恢复背景、裁切、图像比例与前后层次，再检查原生文字；必要时保留复杂区域为 B |
| 合成素材含有预览文字 | 换原始素材或用图像工具取得干净版本；不在残字上叠一套原生文字 |
| PPT 与预览不同 | 以最终 PPT 渲染为准修复字体、裁切和位置 |
| 文件太大 | 查重复媒体、图片像素和压缩；不牺牲必要图纸可读性 |

一次返工应解决明确问题。修复后重看受影响页面；不要重复扩大全套检查或为单页失败新增普遍限制。
