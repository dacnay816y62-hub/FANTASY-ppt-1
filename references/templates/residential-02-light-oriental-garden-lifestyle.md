# 住宅模板 02：浅色东方游园生活方式

## 模板定位

这是面向高端住宅、低密合院、叠墅、改善型豪宅和带会所属性住宅项目的视觉方法参考（适用于可编辑或图像版 PPT）。模板适合表达“城市中的隐逸居所”“当代东方园林”“多元生活方式”“人文艺术生活”的方案汇报。

视觉上采用米白纸本、淡墨纹理、金棕细线、城市与传统文化拼贴、园林意象、空间效果图和软装意向组合。它与住宅模板 01 的黑金深化样板间不同：住宅 02 更轻、更雅、更像一份具有文化叙事和空间策略的东方生活方式提案。

使用时继承叙事结构、页面节奏和气质，不冒用参考项目的名称、原文和设计成果；用户指定的模板与合法提供素材按其要求使用。

## 适用项目

- 高端住宅、合院、叠墅、大平层、低密社区样板区
- 具有会所、归家动线、庭院、泳池、手工坊、书房、茶室等复合生活场景的住宅
- 需要从城市、传统、园林、生活方式、艺术和工艺角度进行完整汇报的项目

## 视觉系统

### 画布

- 比例：16:9
- 16:9 预览可用 1920x1080 或 2560x1440；用户指定其他比例时相应调整。
- 背景：米白、浅灰、宣纸、素麻、淡墨山水、浅色手稿底
- 版式：大留白、细线、圆形裁切、横向长图、轻量拼贴
- 节奏：浅底文化页与全幅空间效果图交替，避免全 deck 过暗

### 色彩

- 主色：#EEE7D8、#E5DDCC、#D5C8B2、#F6F1E8
- 文字：#2A2924、#4A4034、#6D5A3D
- 点缀：暗金、赭石、墨绿、朱砂红小点、石灰灰
- 禁忌：厚重黑金、强商业红、霓虹色、过度饱和蓝紫

### 字体气质

- 中文标题：现代宋体/细宋气质，适合文化与东方审美
- 英文：细字重无衬线，字距可略宽
- 目录和章节可使用竖排小字，但主体内容必须易读
- 每页文字保持短句化：标题、关键词、1-2 句判断、少量图注

### 图像气质

- 城市页：城市夜景、商业活力、传统市集、手工艺、地标、街巷拼贴
- 场地页：灰度航拍、红色点位、浅底地图、基地边界
- 园林页：庭院、水面、亭、树影、石、廊、光、藏露、开合
- 生活方式页：艺术、手作、阅读、茶、花艺、音乐、运动、社交、亲子、收藏
- 空间页：明亮自然光、温润木色、石材、织物、庭院景观、室内外无界

## 叙事关键词

优先从项目资料中提炼关键词。以下是已有场地问题能支持时的示例，不能把词语倒推成未经确认的场地事实：

- **隐**：独品避世一方天地，回应城市界面喧嚣
- **游**：立体的东方园林，回应场地高差和空间层次
- **界**：自然与空间无界对话，回应有限面积和内外关系

这三个词不是固定文案，可以根据项目替换为同级概念，例如：藏、游、境；隐、园、艺；城、园、居。

## 弹性内容模块

按资料深度选择模块，不把大型参考项目的页码当作本次页数。小型试做可选命题、手法分析、氛围与材料；深化才加入真实平面和专项。

| 模块 | 重点 |
|---|---|
| 场地问题 | 只保留能影响设计动作的城市、基地与使用条件 |
| 设计思考 | 从条件推到明确的空间策略，再决定是否需要诗意关键词 |
| 园林手法 | 挑选适用的开合、藏露、借景等方法，说明具体作用位置 |
| 生活方式 | 把活动与空间连接，不强行补全客群人设 |
| 材料器物 | 说明材料、工艺或家具如何承载生活体验 |
| 空间呈现 | 按当前任务选择空间大图、氛围拼贴或细部 |
| 平面与专项 | 仅在有可靠图纸和相应设计资料时展开 |
| 收束 | 回答开场问题，提出下一步可验证的决定 |

## 页面模块规则

### A. 封面

- 米白纸本背景，极淡山水、花枝或园林线稿
- 项目名居中或略偏上，字号克制
- 适合加入小型印章式符号、金棕细线、浅灰纹理
- 不要使用厚重黑底，也不要做成房地产营销海报

提示词要点：

```text
生成一张 16:9 高端东方住宅封面视觉素材，米白宣纸质感背景，极淡东方园林线稿与浅墨树影，中央保留项目名排版空间，整体留白充足、雅致、安静、带当代东方气质，金棕细线点缀；不生成文字、Logo 或水印。项目名与副标题在 PPT 内原生排版。
```

### B. 目录

- 浅米底，目录文字可竖排或细线分栏
- 建议章节：项目解读、设计思考、设计手法、平面分析、方案呈现、专项分析、软装意向
- 目录不做彩色卡片，保持书籍目录感

### C. 城市面貌页

- 用城市夜景、地标、商业街巷、传统手工艺、生活片段做拼贴
- 标题可使用“世界的城市 / 城市的传统印记”类句式
- 表达项目所在城市的现代性和文化底色

### D. 区域/基地分析页

- 灰度航拍或浅色地图为底
- 用红色点位或细线标出项目位置
- 内容包含交通、教育、医疗、商业、公园、自然资源、城市界面
- 文字必须压缩成短句和标签

### E. 场地思考页

- 先提出一个问题：如何结合场地条件制定因地制宜的设计策略？
- 用少量明确的设计动作回应已确认的场地限制，再提炼关键词
- 常见对应：
  - 城市界面喧嚣 -> 隐
  - 场地有高差 -> 游
  - 面积有限制 -> 界

### F. 设计思考页

- 中央用圆形、关键词或关系图表达核心概念
- 关键词组合：生活方式、东方、人文、艺术、园林
- 画面要像概念推导，不像普通 moodboard

### G. 园林策略页

- 重点表达东方园林不是装饰，而是空间组织方法
- 选择本项目实际采用的风景开合、空间对比、藏露或室内外关系，解释作用与位置
- 可用庭院照片、山水图、路径线、剖面和空间效果图组合

### H. 生活方式页

- 用拼贴方式表达多元生活方式
- 可包含：艺术收藏、手工坊、茶室、阅读、聚会、健身、亲子、花艺、音乐、餐叙
- 每一项要能落到具体空间，不要只做漂亮图片集合

### I. 工艺/器物页

- 将传统工艺、器物和现代材料结合
- 可表达：木作、石材、织物、金属、手工肌理、屏风、灯具、家具、茶器、艺术品
- 目标是“服务当代雅趣生活的器物”，不是材料表

### J. 空间呈现页

- 可采用浅底圆形意向图 + 大图空间效果图，也可使用全幅效果图
- 每页一个空间主题，标题要有诗意但不空泛
- 常见空间：
  - 归家门厅
  - 会客厅
  - 艺术楼梯
  - 书房/手工坊
  - 茶室
  - 泳池/泡池
  - 庭院
  - 多功能会客
  - 地下空间

### K. 平面分析页

- 浅色图纸底，功能区用虚线框或淡色块标出
- 重点讲空间序列、游线、动静分区、室内外关系
- 不要把图纸做得太花，图纸清晰优先

### L. 专项分析页

- 用系统化页面讲节点深化
- 可包含：天花系统、灯光系统、地铺系统、墙面系统、构造节点、材料收口
- 适合浅底 + 局部大样 + 材料照片 + 简短说明

### M. 软装意向页

- 米白或浅灰底，杂志感拼贴
- 分类：家具、灯具、艺术品、器物、花艺、织物、绿植
- 可做封面式 moodboard，但不要变成品牌广告

## 设计手法库

当需要扩展“设计手法”章节时，从以下手法中选择：

- 藏与露：入口收敛，转折后打开主景
- 开与合：空间尺度一紧一放，形成游园节奏
- 借景：把庭院、树影、水面、天光引入室内
- 框景：窗、廊、屏、门洞成为观看装置
- 渗透：室内外材质和光线互相延展
- 交叠：路径、楼梯、平台、夹层形成立体游线
- 留白：用空白和浅色材料降低视觉噪声
- 器物化：家具、灯具、艺术品成为生活仪式的载体

## 输出检查

- 是否区别于黑金样板间模板，保持浅色纸本和东方雅致
- 是否讲清城市、场地问题和设计策略之间的关系
- “隐、游、界”或替代关键词是否贯穿全 deck
- 园林手法是否转译为空间组织，而不是只做装饰
- 生活方式、工艺、器物、软装是否能落到具体空间
- 平面和专项分析是否保持图纸清晰、说明简洁
