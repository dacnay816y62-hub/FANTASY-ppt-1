# 住宅模板 01：黑金东方豪宅样板间

## 模板定位

这是高端住宅/样板间设计方案的视觉方法参考（适用于可编辑或图像版 PPT）。它适合住宅、别墅、叠墅、大平层、豪宅样板间和私宅深化方案，尤其适合需要表达“生活方式 + 家庭画像 + 空间策略 + 重点空间深化”的项目。

参考气质来自高端样板间深化方案的通用规律：黑底、低饱和、暖金强调、东方自然、人文生活方式、成组空间效果图与材料意向。使用时只继承版式逻辑和气质，不冒用参考项目的名称、文案和设计内容；用户指定的模板与合法提供素材按其要求使用。

## 视觉系统

### 画布

- 比例：16:9
- 推荐尺寸：1920x1080、2560x1440 或 3840x2160
- 背景：深黑、炭黑、暗灰渐变；可叠加极淡线性纹理、山水雾化纹理、建筑等高线、材质微纹理
- 留白：大留白，不做满屏信息堆叠

### 色彩

- 主色：#050505、#0B0B0B、#151515
- 辅色：#2A2927、#3A3733、#C8B07A、#D8C9A2
- 点缀：暖金、米灰、玉石白、木色、低饱和绿
- 禁忌：高饱和大面积金色、商业海报式强渐变、花哨霓虹色

### 字体气质

- 中文：现代宋体/细黑体气质，标题可偏优雅 serif，正文偏轻量 sans
- 英文：细字重现代无衬线，字距可以略宽
- 文字量：每页 1 个主标题 + 1 句核心判断 + 少量标签；不要大段正文
- 中英关系：中文为主，英文作副标题或小型标签

### 图像风格

- 空间图：低饱和暖色、高级住宅摄影、自然光与洗墙光、木石皮革织物材质清晰
- 人物/生活方式：不要过度商业广告感，使用剪影、局部、黑白人物、意向图拼贴
- 材料页：深灰底上陈列家具、灯具、织物、石材、木皮、金属、器物
- 平面页：黑底灰白线稿，功能区用柔和色块或细线标注

## 弹性内容模块

先判断这是私宅、样板间还是生活方式概念提案，再选内容。篇幅取决于资料与用户要求，不默认扩出完整家庭画像和所有空间。

| 模块 | 应说明什么 |
|---|---|
| 居住需求 | 谁使用、什么活动需要怎样的空间；身份与兴趣只使用真实资料或明确假设 |
| 核心判断 | 需求与场地有哪些冲突，优先改善什么 |
| 空间策略 | 公私、动静、收纳、社交或室内外关系如何组织 |
| 平面优化 | 仅依据已有图纸解释前后变化；缺图纸时改用功能关系示意 |
| 重点空间 | 以必要的大图、分析或局部细节说明策略结果 |
| 材料与软装 | 使用位置、质感、触感和整体关系；不堆商品 |
| 收束 | 本次确认方向和下一步需核实的条件 |

## 页面模块规则

### A. 封面

- 黑色背景，极淡山水/线稿/纹理作为底
- 项目名称横向置中或偏左，字号克制
- 页脚放品牌/团队名
- 本方法可优先尝试留白封面；若完整空间图更能建立主题，可使用大图

提示词要点：

```
生成一张 16:9 高端住宅封面视觉素材，深黑背景，极淡东方山水线性纹理，中央偏左保留项目名称排版空间，整体克制、留白充分、暖金细线点缀；不生成文字、Logo 或水印。项目名与副标题在 PPT 内原生排版。
```

### B. 目录

- 黑底，中央小标题 `CATALOGUE / 目录`
- 三到四个横向章节卡片：01 概念分析、02 平面布局、03 空间方案、04 材料深化
- 卡片用灰度空间纹理或局部意向图做底，不要彩色堆叠

### C. 城市/文化背景

- 可用城市远景、地貌、水系、园林、建筑纹理作为大底图
- 中央一句主题判断，暖金关键词突出
- 文字控制在 20-40 字

### D. 生活方式主张

- 深色全幅背景图或抽象空间图
- 一句长标题表达居住理念，例如“让家成为时间、艺术与自然共同生长的容器”
- 下方 3-5 个短标签：艺术收藏、家庭社交、自然疗愈、智能生活、东方秩序

### E. 家庭成员画像

- 左侧人物黑白或低饱和意向图，右侧 3-4 张兴趣图拼贴
- 按实际成员或使用活动命名；不以性别预设兴趣与空间分工
- 按资料需要选取活动、兴趣与空间诉求；不补造身份、年龄和第一人称原话
- 简单需求可合并；不同活动确有冲突时再分开表达

### F. 空间功能定位

- 拼贴式 moodboard：茶、花艺、音乐、艺术、酒、阅读、庭院、智能面板等
- 中央或右侧写核心定位：自然第一居所、艺术收藏之家、家庭社交场、静修栖居等
- 用线条或小标签连接“兴趣 -> 空间功能”

### G. 楼层/功能关系

- 用横向楼层剖面或堆叠条带表示 B1、1F、2F、3F
- 每层分区用低饱和彩色块标识，标注公共、私密、服务、户外、运动等
- 页面偏理性，但仍保持黑底高级感

### H. 平面优化页

- 黑底，主平面图占页面 60%-75%
- 左侧或下方编号列出空间名称
- 可加入前后对比、动线箭头、问题点/优化点
- 图纸不要太亮；线稿灰白，功能色块低饱和

### I. 重点空间大图页

- 一张空间效果图占 70%-85% 宽度
- 深灰边界，四周留出页眉、页脚和小型平面定位图
- 页眉格式：`DESIGN 方案展示 / DISPLAY {楼层}`
- 标题格式：`餐厅 / DINING ROOM`
- 适合展示客厅、餐厅、主卧、卫浴、庭院、地下会客厅

### J. 材料/软装意向页

- 深灰背景
- 以家具、灯具、材料、器物分组陈列
- 每组 1-3 个短标签，不要写说明长文
- 画面要像设计公司 moodboard，不像电商商品页

### K. 结束页

- 用简短判断回应开场，并指出下一步要核实或选择的事项
- 用户明确要感谢页时可额外设置；项目名和公司名使用真实资料

## 页眉页脚规范

- 页眉左上：章节/页面英文小标 + 中文标题
- 页脚居中或右下：品牌/团队名
- 页码右下角，红色或暖金极小点缀可用于定位
- 每页页眉位置固定，除封面和结束页外不要漂移

## 内容改写规则

- 把用户资料中的长段落压缩成“主题句 + 标签 + 图像线索”。
- 住宅项目必须先讲“谁来住”和“为什么这样住”，再讲“空间怎么组织”。
- 如果未提供家庭资料，优先以活动需求组织内容；确实需要模拟画像时，明确标注假设并保持精简。
- 如果没有平面图资料，不要伪造具体户型图；改用“功能关系示意”和“空间体验路径”。
- 如果没有效果图资料，可生成“概念空间效果图”，但不要声称为真实落地效果。

```text
- 主标题：

- 不要出现的文字：

版式：
- 页面类型：
- 主视觉位置：
- 图文比例：
- 页眉页脚：

视觉风格：
- 黑底高级住宅方案汇报
- 低饱和暖灰、木色、石材、暖金细线
- 东方自然、人文、艺术收藏、定制生活方式

质量要求：
- 图像素材不生成最终文字；标题、正文和标签在 PPT 内重建
- 不要使用真实品牌 logo，除非用户提供
- 不要把页面做成营销海报
- 不要出现多余英文假字、随机小字和错别字
```

## 输出检查

- 封面、目录、章节页是否建立统一气质
- 家庭画像是否能自然导向空间功能
- 平面/功能关系是否没有伪造不可验证信息
- 重点空间页是否有足够大图和呼吸感
- 全 deck 是否保持黑底、暖金、低饱和、克制留白的一致性
