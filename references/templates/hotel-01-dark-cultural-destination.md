# 酒店模板 01：黑金文化目的地酒店

## 模板定位

这是面向高端酒店、城市度假酒店、文旅酒店、精品酒店和景区酒店的视觉方法参考（适用于可编辑或图像版 PPT）。模板的主视觉参考“黑底金线、地图分析、文化文脉、庭院游线、空间业态展示”的酒店方案表达；文化深度参考“历史沿革、诗词文脉、四时体验、器物纹样、场所命名、服务触点”的策划型文本方法。

使用时继承叙事结构、页面节奏和气质，不冒用参考项目的名称、原文和设计成果；用户指定的模板与合法提供素材按其要求使用。

## 适用项目

- 城市度假酒店、文化目的地酒店、景区酒店、历史街区酒店
- 高端品牌酒店、精品酒店、改造型酒店、文旅综合体配套酒店
- 需要把当地文化转译为空间体验、服务内容和运营场景的项目

## 视觉系统

### 画布

- 比例：16:9
- 推荐尺寸：1920x1080、2560x1440 或 3840x2160
- 版面气质：黑底为主，少量浅底图纸页用于平面和技术页
- 背景纹理：暗色地图、城市肌理、水系、园林线稿、古籍纸纹、远山雾气、庭院树影
- 版式节奏：黑底章节页 + 地图分析页 + 文化研究页 + 大图空间页 + 平面技术页交替

### 色彩

- 主色：#050505、#0B0C0B、#111111、#1C1B18
- 辅色：#B99A4E、#D0B46D、#776445、#E8E0CB
- 文化页可加入：墨绿、灰青、湖水蓝、米白、宣纸灰
- 禁忌：高饱和蓝紫渐变、大面积亮金、电商式大红大绿、夜店感霓虹

### 字体气质

- 中文标题：克制、现代、带东方气质；可用细宋/现代宋体气质
- 英文标题：细字重无衬线，字距略宽，适合 `SITE ANALYSIS`、`CULTURAL CONTEXT`
- 正文：短句、标签、时间轴、图注，不做长篇段落
- 章节编号：可用“壹、贰、叁、肆、伍”或 `01 / 02 / 03`

### 图像气质

- 场地页：深色地图、金色定位、半透明范围圈、道路/水系/资源点标注
- 文化页：古画局部、诗词意象、器物、园林、桥、水、山、花木、手作、茶、香、乐
- 空间页：高端酒店摄影质感，安静、低饱和、材质克制，重视光影和尺度
- 体验页：以“人、物、场、时、事、氛围”组织画面，不做普通功能清单

## 叙事原则

需要文化目的地叙事时，从以下问题中选择对本次汇报有用的部分：

1. 这个酒店为什么属于这里？
2. 这里的文化精神是什么？
3. 文化如何转译成当代酒店体验？
4. 每个功能空间如何承载体验？
5. 客人从抵达到离店，会经历怎样的记忆点？

## 弹性内容模块

按酒店定位、汇报阶段与已有资料选用，不设固定页数。小型概念测试可只检验命题、文化转译、空间/氛围和材料；真实方案再展开区位、平面、运营与专项。

| 模块 | 回答的问题 | 资料边界 |
|---|---|---|
| 场地与资源 | 为什么值得在这里建立这类酒店？ | 区位、交通、气候和竞品须有来源 |
| 文化转译 | 哪种地方方法能进入当代空间？ | 真实文化来源与设计建议分开 |
| 体验组织 | 抵达、停留与离店怎样连贯？ | 时间/季节/人群任选有用视角，不全部展开 |
| 空间组织 | 客流、服务和功能如何协调？ | 真实平面才用于布局论证；缺资料用关系示意 |
| 空间与氛围 | 关键体验如何被看见？ | 用户图、AI 意向、参考案例分别标注 |
| 材料与触点 | 哪些材料、器物、服务承载设计判断？ | 不能把品牌或技术性能意向写成已确认选型 |
| 收束 | 本次需要选择什么，下一步验证什么？ | 回应开场命题 |

## 页面模块规则

### A. 封面

- 黑底，中央或偏左项目名
- 可加入酒店扇形、园林窗、金色细线、城市水系轮廓
- 本方法可优先尝试抽象或局部视觉；项目有强识别的大堂照片时也可作为封面

提示词要点：

```text
生成一张 16:9 高端文化目的地酒店封面视觉素材，深黑背景，极淡城市水系与园林线稿叠影，暖金细线构成东方窗景轮廓，左侧或中央保留项目名排版空间；画面克制、国际化、东方气质；不生成文字、Logo 或水印。项目名与副标题在 PPT 内原生排版。
```

### B. 目录

- 黑底，横向或竖向列出 5-6 个章节
- 建议章节：项目解读、文化文脉、设计概念、平面优化、空间表达、体验系统
- 章节卡片可使用地图、古画、庭院、空间局部做暗纹

### C. 区位/交通页

- 深色地图为底，金色点位标记项目
- 以圈层表达机场、高铁、城市核心、景区、水岸、商业中心
- 每页只讲一个逻辑：区域、交通、资源、竞品，不要混在一页

### D. 气候/季节页

- 用折线、柱状、月度图表达温度、降水、日照、季节
- 目的不是气象报告，而是导向体验：雨、雾、花、月、风、茶、庭院、夜游

### E. 文化文脉页

- 用历史时间轴、古地图、人物、诗词、画作局部构建文化厚度
- 每页保留一个核心判断，例如“城市精神来自水、园林与文人生活的叠合”
- 避免堆满学术长文；把史料压成短句、关键词和图像证据

### F. 文化转译页

将文化内容转译为设计语言，必须形成映射关系：

| 文化母题 | 空间转译 | 酒店体验 |
|---|---|---|
| 山水 | 借景、层叠、留白 | 抵达时的远山/水院记忆 |
| 园林 | 曲折、框景、游线 | 像游园一样进入各功能区 |
| 诗词 | 命名、短句、情绪 | 客房/包间/酒廊的场所记忆 |
| 四时 | 色彩、花木、活动 | 春花、夏荫、秋月、冬雪 |
| 器物 | 材料、艺术品、灯具 | 茶器、香器、瓷器、屏风 |
| 雅事 | 服务内容 | 点茶、焚香、插花、听琴、观鱼 |

### G. 体验系统页

- 不要只写功能清单，要写“客人如何体验”
- 可用时间轴：晨起、午后、薄暮、夜间
- 可用季节轴：春、夏、秋、冬
- 可用人群轴：住客、非住客、商务客、亲子客、宴会客
- 可用场所轴：大堂、餐厅、酒廊、庭院、客房、康养

### H. 平面/动线页

- 可切换浅底技术页，提升图纸可读性
- 按真实功能与资料区分住客、非住客、后勤、宴会或餐饮动线，不为未设功能补造路线
- 用不同低饱和色线标注，不要使用高亮刺眼颜色

### I. 公区空间页

- 一页一个空间或一个空间组
- 标题格式：`大堂吧 / LOBBY LOUNGE`
- 上方保留页眉，主体为大图或拼贴
- 每页必须说明：空间角色、文化转译点、体验触点

常见空间：

- 落客区 / Drop-off
- 接待与礼宾 / Reception & Concierge
- 大堂 / Lobby
- 大堂吧 / Lobby Lounge
- 全日餐厅 / All Day Dining
- 中餐厅 / Chinese Restaurant
- 特色餐厅 / Specialty Restaurant
- 宴会厅 / Ballroom
- 会议前厅 / Pre-function
- 酒吧 / Bar
- 庭院 / Garden Court

### J. 客房页

- 不只展示房间，要讲“停留体验”
- 可表达：窗景、床头、茶台、浴室、衣帽、艺术品、夜床服务
- 命名系统可引用诗词、地名、植物、季节、器物，但必须根据项目文化重新生成

### K. 材料/器物/艺术页

- 从文化来源转到材料：石、木、金属、织物、陶瓷、玻璃、漆、纸、竹、藤
- 从器物转到空间细节：灯具、屏风、花器、香器、茶器、门把手、艺术装置
- 页面像策展板，不像材料供应商清单

### L. 场所命名页

- 为酒店重点空间建立命名系统
- 命名可以来自：地名、水系、园林、诗词、花木、时令、雅事、器物
- 每个命名必须有一句解释和一个体验落点

示例结构：

| 空间 | 命名方向 | 解释 | 体验落点 |
|---|---|---|---|
| 大堂 | 观堂/望境/入园 | 抵达即进入地方精神 | 礼宾、迎宾茶、第一重框景 |
| 茶室 | 梦梁/听雨/煎茶 | 将地方茶事转为停留体验 | 点茶、试茶、香事 |
| 酒廊 | 四艺/花影/月台 | 社交与雅集场景 | 音乐、花艺、夜间酒饮 |

## 文化内涵增强规则

当用户说“文化内涵多一点”时，优先深化与项目判断有关的来源和转译；从以下内容中按需选择，不按数量补页：

- 历史沿革：用时间轴讲城市/场地的形成
- 山水格局：水系、山体、园林、视线、到达关系
- 文人生活：茶、香、花、画、琴、书、宴、游
- 四时体验：春夏秋冬对应活动、花木、色彩、餐饮和服务
- 器物纹样：瓷器、花器、香器、屏风、窗棂、纹样、材料
- 场所命名：把文化转化为大堂、餐厅、酒廊、客房、庭院命名

文化页必须落到空间和体验，不能停留在资料罗列。每一类文化都要回答：

```text
文化来源是什么 -> 可提取什么关键词 -> 转译成什么空间语言 -> 客人如何感知
```

## 输出检查

- 是否讲清“酒店为什么属于这个地方”
- 是否有足够文化研究，而不是只有空间效果图
- 文化是否转译成空间、服务、命名和体验
- 平面和动线是否支持酒店运营逻辑
- 公区、餐饮、宴会、客房、康养是否有清晰模块
- 全 deck 是否保持所选视觉方向，图像和文化研究是否服务具体设计判断
