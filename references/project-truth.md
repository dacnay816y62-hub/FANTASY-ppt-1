# 资料属性与空间证据

## 四种属性

| 属性 | 含义 | 示例 |
|---|---|---|
| FACT | 用户、图纸、现场或可靠来源明确提供 | 用户明确项目城市；图纸标注某处开口 |
| JUDGMENT | 基于事实的解释和设计判断 | 从已知入口与席位关系判断可能受干扰 |
| PROPOSAL | 尚未确认的设计建议或模拟设定 | 建议以错位隔屏改善视线；虚构餐厅名称 |
| UNKNOWN | 缺失且不能可靠推断 | 结构墙位置、准确面积、消防或运营条件 |

在 `project-truth.txt` 记录“内容、属性、来源/依据”即可；复杂项目再加编号便于页纲引用。用户提供的效果图能证明图像中的设计表达，不能自动证明已经建成。

## 条件不等于结论

审查每个关键判断的推导：

> 条件 → 对使用的影响 → 设计动作 → 可展示结果

区分三个层次：照片或图纸证明现状；关系图解释设计建议；AI 氛围图帮助理解建议的感受。后两者不能倒过来证明未经确认的现状或方案性能。装饰图不能当作测量、声学、节能或经营成效的证据。

文化引用需要真实来源。没有资料时可以提出当代设计意向，但不要补造历史渊源、引文、宗教含义或地域专属工艺。

## 缺失资料的处理

没有依据时，不写确定的面积、造价、工期、房量、层高、地图距离、交通时间、竞品排名、品牌型号或技术指标。

- 可以提出“设计建议”“材料意向”“模拟使用者设定”。
- 可以画简化的相邻、经过、视线和功能关系，注明“关系示意，不按比例”。
- 不补造带准确尺寸、朝向、柱网、基地边界的仿真实平面；已授权模拟项目可提出标注“模拟概念平面，非实测”的布局方案，记录假设并让后续效果图保持一致。功能关系示意不能冒称平面图，概念平面不代表可施工成果。
- 只有城市信息时可做可信的城市/片区区位图，不擅自指定基地；地图与平面的具体处理见 [culture-site-plan.md](culture-site-plan.md)。
- 需要图纸才能成立的结论保留为待验证项。资料缺失不必阻止其余已授权工作。

## 图像来源与页面标注

| 素材类型 | 页面表达 |
|---|---|
| 项目实景/现状图 | 使用真实来源和拍摄语境 |
| 用户提供的设计效果图 | 称方案效果图，不声称已落地 |
| 外部案例或摄影 | 称参考案例/氛围参考；备注记录来源 |
| AI 生成素材 | 称“AI 概念意向”或在整套开场说明 AI 图像属性 |
| 功能关系图 | 标明设计建议、关系示意或不按比例 |

对于明确的模拟测试，封面或开场清楚说明“虚构项目 · 概念排版测试”，相关图注保留必要属性即可。观众不能仅因摄影般真实而误认成项目实景。内部 FACT 等代号留在记录中，不需要遍布正式页面。

在 `source-notes.txt` 记录来源及素材属性；将外部资产、外部非平凡事实的来源放入相应 PPT 讲者备注 `[Sources]`。不要虚构图片网址或研究出处。
