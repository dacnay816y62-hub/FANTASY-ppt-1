# 品牌排版与设计师汇报框架

本轮用户要求：用简约、高级的品牌排版，保留设计师的框架与思路，并固定参考图 1 中的目录页。品牌参考主要服务前段文化、概念和氛围；酒店相关参考帮助表达场地、生活体验与空间。它们共用字体、色彩、背景和标注层级，不能拼成两份风格断裂的 PPT。

## 固定目录：参考图 1 左下角

先打开 [图 1 原始参考](../assets/brand-framework-references/01-brand-and-contents.png)。它是一张多页展示板，**目录在左下角，是一张横向页面**；不要把整张竖向展示板当成 PPT 比例，也不要误选其顶部封面或右下概念页。

- **位置与版式固定**：完整方案在封面后放目录；有意设置的短概念引子可在目录前。目录页面左侧约半幅为完整、出血的氛围图片，右侧约半幅为安静的底色。保留这种书页式左右关系，图片占满自己的半幅，不变成悬浮小照片。
- **右侧层级固定**：上方放小而清楚的项目名，中间保留明显空区，下半部放“目录 / CONTENTS”及中英章节。目录标题与章节左边缘对齐，中文为主、英文退一层，不复制原截图的极小字。
- **章节组固定**：默认五章，左列 01–03，右列 04–05；右列从左列第二组附近开始，形成原图三加二的紧凑错位关系。两列底部协调，章名组内中英紧密，组间留出明显间隔。长中文先精简，必要时设计两行；不压成微字。
- **目标画幅落点**：以 16:9 试排时，可从图片 `x=0–50%, y=0–100%`、右侧内容左缘约 `56%`、第二列约 `77%` 开始；项目名在上部，目录标题约在 `48%–55%` 高度，章节区域约在 `60%–91%`。这是观察原图得到的可调起点，最终按实际字数、字面与留白校准。
- **可变内容**：项目图片、名称、底色、字体气质和实际章节名称。沿用用户当前非白底偏好，右侧用安静的暖灰、矿物色、茶褐等项目相容底色或轻质感；不固定米黄纸、森林、蘑菇或原品牌名。项目有明确新增章节时沿用左右半幅母版重排章节组，不为守五个格子隐去实质内容。
- **可编辑性**：项目名、“目录 / CONTENTS”、编号和中英章名均为原生文字；图片为独立对象，A/B 交付不能直接使用截图。目录无需再加第二个左上栏目、底部品牌或页脚导航。页码只有用户需要时才显示，并在最终排页后核对。

## 默认五章：设计内容的组织骨架

| 章节 | 中英章名 | 必须回答的问题 | 主要承载内容 |
|---|---|---|---|
| 01 | 项目解读 / PROJECT CONTEXT | 项目在哪里，哪些条件真正影响设计？ | 项目目标、可信区位图、周边环境、相关当地文化、已知条件与明确假设 |
| 02 | 设计概念 / DESIGN CONCEPT | 从依据中提炼什么，形成怎样的设计方向？ | 核心概念、文化或元素转译、设计动作、唯美氛围及生活方式意向 |
| 03 | 空间规划 / SPATIAL PLANNING | 这个方向如何组织功能、尺度与使用？ | 总平面或对应布局、功能关系、主要动线、必要分区及视角定位 |
| 04 | 空间设计 / SPATIAL DESIGN | 关键空间具体如何呈现？ | 分区域设计说明、空间图、关键视角与局部设计重点；先提供对应平面 |
| 05 | 材质与陈设 / MATERIALS & FF&E | 用什么材质、家具、织物与光完成体验？ | 硬装材料、色彩、家具与软装组合、必要灯具意向和有依据的方案比较 |

这是完整方案的默认目录，用户给定的汇报范围、设计阶段与实际内容优先。住宅软装提案可强化第 05 章，餐厅关注就餐组织，酒店按公共区域、客房等展开第 04 章；不把酒店服务项目复制到住宅或零售。局部试页不强加完整目录，五章也不等于只做五张页面。材料和陈设可在相关空间中先出现，第 05 章用于统整或比较，不重复同一素材填页数。

目录名称应让人知道会看到什么。项目的诗意概念放在封面、概念页或章节副标题，不能把全目录都换成“启、隐、境”等难以导航的词。大号展示字仅用于封面或有目的的章节表达，常规内页保持近读的清楚层级。

## 概念研究阶段：保留目录版式，调整章节内容

用户暂不需要平面与效果图时，完整概念提案仍使用上述半幅图、中英章节和三加二错位的目录母版，可组织为：

| 章节 | 中英章名 | 本阶段重点 |
|---|---|---|
| 01 | 项目解读 / PROJECT CONTEXT | 相关区位、当地文化、目标与设计机会 |
| 02 | 设计概念 / DESIGN CONCEPT | 由对应图像的概念词共同建立项目方向，可辅以一句总概念 |
| 03 | 元素提炼 / DESIGN ELEMENTS | 依据是什么，提取哪些形态、肌理、色彩或光影特征 |
| 04 | 设计手法 / DESIGN STRATEGIES | 如何通过界面、虚实、尺度、光和使用方式转译这些特征 |
| 05 | 材质方向 / MATERIAL DIRECTION | 材料的角色、触感、色彩关系和搭配原则 |

章名按实际内容微调，固定的是目录构图。元素页回答“提取什么”，手法页回答“如何运用、为什么这样做、希望形成何种体验”，避免两章重复同一组关键词。可用文字说明拟应用部位，区分设计建议与已确定条件；无须为了证明设计手法而生成房间、家具定型或平面。保留适用的文化、氛围和抽象演示图，用户指定纯文字时相应停在文字内容。

以下前后段衔接与平面核查适用于已进入空间方案的任务；概念研究阶段检查到设计手法和材质方向即可，不以未制作空间图判为缺项。

## 前后段怎样衔接

1. **前段用品牌排版建立感受**：文化、工艺、人物、自然、服饰或细部按项目筛选，图像与文字共同构图。按 [文化与概念氛围模板](culture-concept-mood-templates.md) 选择图带、拼贴、图内叠字或概念停顿，也可采用本批参考中优质的半幅、渐变融合与主辅叠层。不要让固定模板库排斥用户新提供的构图。
2. **由概念过渡到设计动作**：把前段选定的线索明确用于形态、边界、材料、光或使用方式，随后在平面或构件中看见对应结果。这个过渡可由连续两页或一张有判断的转译页完成，不固定三段流程图。承担抽象推导的元素演示按用户要求使用 Image Gen，文字和必要标注独立排版。
3. **后段按设计师的阅读需要展开**：先看清平面，再看对应空间；必要时用局部、第二视角、材料与陈设补充同一设计判断。空间页让设计对象占主要图幅，短注与对象靠近；不把整组空间页变成酒店设施、餐饮服务或品牌历史的宣传介绍。
4. **统一审美，调整信息密度**：前后段保持同一项目的字体角色、颜色、图片色温和背景规则。说明复杂时分组或分页面，不能在进入平面与材料章节后突然换成商务卡片、厚框表格或巨字标题，也不能为保持唯美而删除必要图纸与论证。

## 验收重点

- 完整提案实际包含指定目录页，目录章节与成品一致；半幅出血图、右侧上部项目名与下部中英章节关系保留，不能仅在文字说明里声称使用模板。
- 前段能看见文化、概念和氛围的图文构图，后段能看见平面、空间、材质和陈设的对应；两段共用视觉系统，概念中的重点在后段实际出现。
- 当地文化、区位与对应平面依 [culture-site-plan.md](culture-site-plan.md) 核查；漂亮的酒店宣传图不计作设计依据、区位图或项目效果图。
- 对照参考检查留白、文字密度与图幅。厚重装饰、弱对比小字、长双语段落和夸大的普通标题不因出现在参考中而保留。

## 结尾：设计愿景与致谢

- 当前提案默认以“设计愿景 / DESIGN VISION”和“谢谢 / THANK YOU”收束。结合项目写一句简短愿景，必要时加一句具体体验说明，回应前面的概念和设计动作。避免通用口号和每个项目相同的文案。
- 用项目自身的氛围底图承托文字，延续原有字体与配色。可用满幅影像、半幅或渐变衔接，按图片留白选构图，不统一成同一个结尾模板。背景清楚可辨，愿景为主、致谢为次，A/B 交付保留原生可编辑文字。
- 不默认以“深化重点、下一步验证、待核对事项”等工作清单结束。确有价值且用户需要的技术事项放在相关正文、备注或附录；重要事实限制仍须如实保留。
- 编辑旧稿时识别实际末页内容。用户明确要求删除末页则替换该页；若只要求加入结尾，保留有价值的材质、收边、陈设等正文，并追加收尾。局部试页或用户另有结尾要求时遵守范围。
