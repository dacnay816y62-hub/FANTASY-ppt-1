# 页纲与设计判断

## analysis.txt

只记录对提案有影响的信息：

```text
项目：名称 / 类型 / 场地 / 汇报阶段
沟通任务：汇报结束时，谁应该理解或选择什么，因为何种依据。
核心判断：已知条件或明确假设 → 使用问题/机会 → 设计动作 → 可展示结果。
资料状态：已确认 / 建议或模拟 / 未知。
篇幅与视觉方向：沿用用户要求，或简述本次选择理由。
```

完整提案需要核实并筛选当地文化依据，具体见 [culture-site-plan.md](culture-site-plan.md)。不要编造文化故事、客群人格或整套运营定位；文化分析只保留实际支撑后续元素和空间的线索。

## outline.txt

完整提案采用 [品牌排版与设计师框架](designer-report-framework.md)：包含指定半图目录母版，以“项目解读、设计概念、空间规划、空间设计、材质与陈设”为默认五章。按实际范围调整章名和展开深度，目录与成品一致；局部试页不强制补全。文化与氛围最终须连接到设计动作、平面和空间结果，不将前段扩成独立的企业品牌介绍。

每页保留五个字段；以下标记可存为纯文本，供辅助脚本识别。

```text
## Slide 01｜页面标题
- 这页要证明什么：一个具体判断，或开场要建立的项目方向。
- 页面文字：观众能直接读到的标题、短句、图注。
- 视觉证据：哪张图/何种关系支持判断；区分事实图和意向表达。
- 版式结构：主次、图文比例、阅读顺序和图像裁切。
- 资料属性：FACT / JUDGMENT / PROPOSAL / MIXED，附必要依据。
```

必要时才补“图纸边界、资料限制、同场景不变项”。有整页视觉稿时，在版式结构中关联该稿并简记要保留的图像比例和叠层，不增加一套重复页纲。不要把制作流程、图片提示词、测试评分或待办事项写进观众可见文字。

完整提案的页纲须安排文化依据、区位/位置图与效果图前的对应平面，按 [culture-site-plan.md](culture-site-plan.md) 检查资料是否可用。页面可合并或分组，顺序服务叙事；没有地址或图纸时写明可完成的尺度与实际缺项，不把占位标题计作内容完成。

## 内容检验

- 文化：分析中的线索是否在后续元素或空间中实际使用？声称来自当地的设计是否能追溯到依据？
- 区位：是否有可信的地理位置图与周边关系，项目标记和距离是否有依据？
- 平面：是否先于对应效果图，是否属于同一楼层/区域/房型，图中的入口、门窗与家具关系是否相容？
- 概念：抽象关键词后面是否有具体设计动作？如“界面轻重交替”应能指出隔屏、开口、材料或光的变化。
- 分析：图是否帮助理解同页判断？漂亮纹理、无标注的随意箭头不构成分析。
- 氛围：图片是否共同支持一种具体感受？每张图是否有不同作用，避免同类图重复凑数。
- 材料：是否说明使用位置及对光、触感、边界或维护的影响？未核实的性能留待样板验证。
- 收束：是否回应开场目标，并提出下一项有依据的设计决定？不必另加一张空白感谢页。

## 素材记录

在 `source-notes.txt` 或相应提示词 `.txt` 中记录：编号/文件、用途、来源与属性、裁切要求。重建整页稿时注明素材对应区域及原生/独立图片/合成区域，便于复查。需要同场景多图时再加必须延续的要素。默认不重复使用同一张图片，确有对比或定位用途时保留理由；统一背景允许复用。

## 文字

标题可以是短而准确的空间名称，也可以是完整判断句；不强迫每页用同一种句式。正文压缩为“判断 + 依据/动作 + 结果”。先删同义重复和无信息英文，再处理字号。按实际版式设计断行，单行标题不得意外换行。
