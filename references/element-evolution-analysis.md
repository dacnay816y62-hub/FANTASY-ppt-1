# 元素演化分析

用于文化元素提炼与设计手法说明。用户参考见 [源像与转译对照](../assets/analysis-evolution-reference.png)，先查看原图，再提取其中可迁移的比较关系。参考中“故宫、景德镇、苗族”的案例和多栏密度不是通用目录。

## 图像应解释的事情

- 让观众辨认原始线索，以及究竟抽出了什么：轮廓、色块、层理、节奏、疏密、构成、透光或明暗关系。
- 在后续图中保留至少一个视觉锚点，使演化可追溯。不能从红墙突然跳到无关的玻璃雕塑，只靠文字宣布两者有关。
- 设计结果可为平面线面构成、界面分段、材料叠合、概念剖示或有意义的局部关系。概念研究阶段不要求完成空间效果图，生成图也不证明构造已验证。
- 可用源像与结果一一对照、局部放大、少量连续变化、两条线索并行等构图。根据要说明的差异确定步数与图幅，避免每页固定三个步骤。

## 素材与排版

- 原始文化与氛围素材优先网上精选，事实属性可追溯；找不到真实来源时，生成图只作明确的意向或通用形态样本。
- 美术化的提取与演化图仍使用 Image Gen，允许其生成干净线稿、轮廓、平面色块、纹理转译和概念剖示，不限于体块渲染。不要用程序线条、箭头、方框代替核心分析。
- 短标题、图注、编号和必要导向箭头原生可编辑。箭头只提示阅读方向，核心关系应在图中成立；不给无关图片加箭头冒充演化。
- 图文共享对齐轴，来源与转译之间保留尺度联系；按用户现有品牌排版控制正文大小、图注密度与背景质感。
- 在讲者备注区分来源事实、形式归纳与设计建议。精确地理、尺寸、工程或光学数值采用可靠数据，不能由生成图替代。

## 验收

暂时不读文字：能否认出同一个来源、看出哪一项特征被保留、说明结果改变了什么？若只能说“几张都很高级”，分析尚未成立，应重做对应关系。形态自由与推导可读同时满足。
