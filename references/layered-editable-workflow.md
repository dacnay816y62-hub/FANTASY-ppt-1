# 从整页视觉稿到可编辑 PPT

## 选择编辑等级

| 等级 | 组成 | 适用 |
|---|---|---|
| A：原生可编辑，默认 | 标题、正文、标签、页码为原生对象；概念演示与摄影等视觉素材独立放置 | 后续需要改文案、替换图片和持续深化 |
| B：混合可编辑 | 复杂拼贴/纹理合成为图片，关键文字原生 | 艺术化封面、文化或氛围拼贴 |
| C：整页图像 | 每页为图片；明确文字不可直接编辑 | 用户要求图片版或纯图像设计稿 |

用户的格式选择优先。A/B 中“可编辑”指文字和对象可修改，并不意味着摄影图、渲染图或每个纹理都能在 PPT 中拆开。

## 1. 用整页视觉稿确定构图

新提案或视觉重做，先选代表页，用图像工具生成完整画幅的视觉稿。已有明确模板或只改局部时直接编辑原 PPT，无须重新生成整页。

每页提示词根据页纲与参考写清：

- 画幅与汇报场景，页面要表达的判断；
- 文字角色、准确短标题与预留区域，封面展示字和内页标题分别控制；
- 主图、分析、文化/生活方式、细部等素材的分工与大小关系；
- 背景材质、前后层次、裁切、留白和阅读顺序；
- 必须延续的项目要素，以及真实资料与概念意向的边界。

整页稿可以包含短标题以判断构图，但其中的字形、字号、长文和数字都只是预览，不能作为最终文字依据。元素提炼、概念转译和空间策略演示须用 Image Gen 展示材质、体积与光影，标签另建。精确数据图表、真实图纸与有据工程连接使用可靠来源或确定性方法；不要让模型重画这些精确证据。

检查图像是否丰富而有主次、分析是否支持观点、底纹是否影响阅读。构图问题先改视觉稿，不把未成立的方向批量复制。方向成立后记录主要区域、比例与叠层顺序，再重建代表页；其余页面可分批设计和重建。未约定审批节点时自主继续。

## 2. 准备干净的独立素材

逐项决定保留什么、怎样得到干净素材。优先复用用户原始文件和已有无字素材；需要生成或编辑图像时使用图像工具，并提供相应视觉稿作为参考，延续构图、色彩与主体。

| 内容 | 重建方式 |
|---|---|
| 标题、判断句、图注、页码、分析标签 | 按核准文案新建 PPT 原生文本 |
| 少量圆点、方块色样与必要图例 | 原生形状，服务主次或对象对应，不拼装概念流程图 |
| 元素提炼、概念转译、边界与材料策略演示 | Image Gen 无字独立图像，以体积、材质或光影显示判断；说明另建原生文本 |
| 纸纹、织物、石材微纹理等底层 | 独立无字背景图片，控制纹理强度 |
| 摄影、空间、材料图 | 独立图片与明确裁切；普通矩形照片无需透明背景 |
| 器物剪影、不规则叠层 | 按需生成/编辑为透明 PNG，检查边缘和残字 |
| 难以分离的复杂文化/氛围拼贴 | 保留干净的合成区域，文字与关键标注另建，归为 B |
| 真实平面、地图、精确节点与数据图表 | 可靠图纸、可验证矢量或可编辑图表；不以 AI 补造缺失信息 |

“拆层”是有依据地整理、重新生成或重建素材，不是从单张扁平图自动恢复被遮挡的全部原始图层。图文粘连时优先用原素材或生成干净版本；简单底色可以原生重建。无法分开的区域明确保留为 B，不用带字整页图再叠一套文字伪装可编辑，也不裁掉关键视觉来迁就文字。

透明素材若保留了整页画布，可按 alpha bbox 裁去透明空白，并按原坐标放回，避免图片选择框覆盖整页。只有确有透明边缘时才需要这一步。素材记录简记“文件 / 对应页和区域 / 原生或图片 / 位置与裁切 / 来源属性”。

## 3. 原生重建并对照视觉稿

- 按当前 Presentations 规定的构建工具与运行时制作 A/B/C；不因图像版或拆层路线改用过时依赖。
- 先恢复背景、主要图像的比例与叠层，再按项目字体角色放置原生文字，最后加标注与页码。字体真实 pt 值由文字规范控制，不照抄生成图的偶然字形大小。
- 对关键对象命名，保持文字与图片可独立选取；不能通过一个整页背景对象宣称全页可编辑。
- 使用明确的 cover/contain 与 crop，禁止拉伸；图纸尽量完整保留，氛围图按主体裁切。裁切须在最终导出的 PPT 上复查。
- 概念图核对物体形态是否实际支持观点、标签是否对应，不以漂亮静物代替分析。精确工程连接另按可靠依据核对，不以图像生成替代。
- 外部素材和来源事实写入对应页讲者备注 `[Sources]`；AI 素材标明其概念属性。
- 摄影通常用高质量 JPEG，透明素材用 PNG；保持必要清晰度并去除无用的重复媒体。

渲染代表页 PPT，与整页视觉稿并排查看背景质感、图像大小与裁切、叠层、阅读顺序和密度。允许为准确文案、真实字体和可编辑性作有意调整，但不能在重建时丢掉参考的主要视觉关系，退成默认网格。代表页重建成立后继续其余页。

## 检查与交付

从最终 PPT 渲染每页并检查；整页视觉稿不能代替成品渲染。A/B 核验关键文字确实存在于可编辑对象中，并可独立选取相关素材；C 明确为图片版。封面或纯视觉页允许有意少文字，不以对象数量代替编辑质量。记录 B 的合成范围与实际限制，不承诺自动无损拆层。

`scripts/merge_images_to_pptx.py` 通过受管 JavaScript 运行时调用 `@oai/artifact-tool`，仅用于 C。默认 contain 保留整页内容，使用 cover 前检查边缘文字。C 的项目校验使用 `validate_project.py <project-dir> --stage final --mode image-only`；A/B 保留默认 editable 检查。

交付用户请求的最终文件；用户需要源文件时再提供构建文件、原始素材和 `.txt` 记录，不自动附上完整中间目录。
