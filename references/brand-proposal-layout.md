# 品牌提案的内页比例

用于品牌提案、方案册的近读排版，尤其处理“太满、内页字太大”的返工。沿用项目素材与非白底等已确认方向；不把品牌参考的配色、标识和图案强加给空间项目。

当前用户进一步指定“品牌排版＋设计师框架”，新增十二张参考的取舍和固定目录见 [designer-report-framework.md](designer-report-framework.md)。这一轮具体选择优先：品牌式构图重点用于前段文化、概念与氛围，酒店相关参考用于场地和空间的表达；后段图纸与材质继续保持同一套简约视觉系统。

## 参考应改变哪些决定

查看真实参考内页，不从封面、搜索摘要或字体表独自推导整套排版。简记每个可用页面的：标题字面与画幅比例、正文列宽、主图与辅助图大小、说明与主体的间隔、连贯空区。小缩略图只能支持大关系判断，不能据此声称测得准确 pt。

先区分问题：文字角色整体过大、强调层过多、图幅铺满、底纹过强，或几项同时发生。按问题重排现有内容：

- 标题保持导航或观点作用，必要的说明退为正文；不强制每页另加大号判断句。
- 主图拥有一个完整区域，辅助图按证据价值选择大小。图注靠近对应图像，不挤进相邻组或页脚。
- 让空区服务阅读顺序、图文分隔或章节节奏；减少满宽边框、重复底框和横贯页面的装饰线。
- 底纹保留材料感，同时让正文与分析线周围安静。留白可以是灰绿、茶褐等有质感的空区。
- 分析页、氛围页与结尾分别试排，避免整套都是“顶栏大标题＋铺满的图＋底部大图注”。

字号起点与画幅关系统一放在 [typography-lock.md](typography-lock.md)。调整完成后同时看单页与全套节奏；不以统一缩放、删除大部分有效素材或不断添加空页代替排版。

## 多批参考合并后的排版判断

把各批参考放在同一页序下比较，按「素材角色、图文锚点、阅读顺序、应舍处理、落地页」记录取舍。区分本次实际打开的原图、保存的行业代表页与此前筛选记录；无法重读原 PDF 时，不声称刚通览全文。品牌展示板中的外框、阴影与宣传落款不是幻灯片本体。

| 内容任务 | 优先学习的关系 | 不随参考继承 |
|---|---|---|
| 文化与工艺 | 软山/CUNZU 的清楚主体、手作近景；文化工艺参考的主景与局部互证 | 同尺寸百科图片墙、长段双语、每页固定花框 |
| 概念氛围 | 满幅影像的天然空区、康莱德的连续图带、双联页的两种气质对照 | 把复杂图像一律压暗再堆大字、把纯色金句当默认停顿 |
| 元素与演化 | 凤栖、Fendi 与源像转译参考中的可追溯对应；让结果与来源按证据价值分大小 | 强制每页三等分、来源和结果总是等权、无说明的漂亮抽象物 |
| 场地与设计 | 悦榕庄参考的清楚地图关系；领邸的主图与辅助细部 | 生成假地图、为套版虚构定位图、酒店营销内容代替设计论证 |
| 材质与收尾 | 康莱德的软硬材质成组；品牌摄影用身体与触感回扣体验 | 每个样品加卡片框、再次重复封面与页脚、无图支撑的长篇口号 |

**先决定一页的视觉主语，再决定标题位置。** 主语可以是源像、演化结果、主景或材料组，不能每页都默认是大标题。普通标题先精简成一个判断；中英栏目清楚可读，英文退一层，说明和图注靠近对象。用共享左缘、共用基线、紧密组距或有意义的压图建立关系，不把图片散落当作灵活排版。

检查连续三页的轮廓：若都呈现「顶栏标题—满宽图阵—底部说明」，根据内容改变其中一页的焦点或密度，例如结果主图配较小来源、侧题配同构比较、影像条带配完整空区。不要轮换同一套三模板来伪装变化；承担比较的图阵可以保持同构，变化必须帮助理解。分析演化的对应要求不等于固定三步等分版式。

保留纹理，同时压低其存在感：缩略看时先读到图像与文字，放大后才感到纸、矿物或织物的质感。原生透明底色层可用来统一材质底，不覆盖证据细节。重排既有素材优先使用 PPT 原生裁切与独立图框；明确的来源到转译对照允许复现同一源像，备注说明其对应作用，不为填满页面重复照片。

## 封面、聚合与文字节奏

- 此工作流的封面优先采用极简满版底图，或半幅主体自然渐变融入材质底色；图像参与整体构图，避免一张有明显硬边的照片孤立插在大标题旁。字号服从构图，不能靠放大内页文字延续封面力度。
- 主辅图片可以大小不同，但须形成共享边缘、紧密间隔或明确叠层的视觉组。先建立一个焦点，再安排辅助证据；不要把“不等大”做成散落四角。局部特写与连续氛围图带有助于强调主体，应保留有效裁切；用户已认可的页面默认锁定，除非明确要求修改。
- 一页文字区分主判断、次级解释和图注。允许少量字重或字号差异，但避免每段都成为同等强度的“标题＋正文”，也不每页追加大号金句。后半段通过文字分组、图幅和空区变化保持节奏。
- 顶部栏目使用清楚可读的中英双语，具体角色规则见 [typography-lock.md](typography-lock.md)。本工作流默认不重复放置底部品牌名、英文栏目与页码；用户明确需要或既有品牌规范要求时再保留。删除页脚不等于删除正文图注、项目名或必要来源说明。
- 小圆点、小方块可作视觉锚点、材料色样或局部编号。控制数量与对比，服从图文对应；不用它们搭起新的流程模板，也不加满宽装饰线和无意义底框。
- 元素提炼与概念演示使用 Image Gen：把材质、体积、构件变化或光影差异直接展示出来，配短而可编辑的说明。不得回退为原生线条拼装；精确图纸与数据遵循真实性规则。

## 空间提案的优先参考

用户提供的行业提案及按页筛选见 [benchmark-selection.md](benchmark-selection.md)。排版取康莱德的图带与材料组、领邸玖序的主辅尺度；分析取凤栖逸庐的原型转译、苏州文华东方的连续设计生成。各取所长，不把其中白底、超大内页字、弱对比或拥挤拼贴一并继承。参考文件比例各异，迁移时比较相对画幅，不照抄绝对 pt。

## 辅助品牌实例

以下只补充阅读比例，不是指定模板；当前用户提供的空间行业参考优先。

- [Hotel Boulderado Brand Style Guide 2017](https://www.boulderado.com/wp-content/uploads/2019/04/HB-Brand-Standards-Guide-Lines-2017.pdf)，第 3、5 页：说明限制在明确列宽内，标题与主体之间保留空间。借鉴文字退让与内容分区，不照搬其白底或品牌侧栏。
- [Light Human Hotel brand book](https://www.slideshare.net/slideshow/brand-book-lighthumanhotel/78308302)，第 5、17 页：不同阅读角色分列组织，展示内容和说明各有位置。查看页面图像后再决定具体可借鉴的关系，不把英文字体示范值机械套到中文稿。
